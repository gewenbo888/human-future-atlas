# The Human Future Atlas · 人类未来图谱

A bilingual, public-interest atlas of humanity's long-term challenges, civilizational milestones, possible futures, and the actions any one person can take, today. Designed as a digital exhibition: serious, elegant, and deliberately calm.

The site is a single static HTML file. It runs entirely in the browser — no backend, no database, no login, no external paid APIs, and no personal data collected. Reflections on the wall live only in the current browser tab.

## Sections

- Hero · Mission · 12 Global Challenges · Timeline of Human Progress · 4 Future Scenarios · 8 Ethical Tech Principles · Personal Action Planner · Global Impact Dashboard · 6 Stories of Hope · Reflection Wall · Resource Library · FAQ
